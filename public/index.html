Agent Stack Lab · five layers, one failure mode

One missing layer.
The agent still breaks.

A travel-assistant agent ran the same request four times. With every layer enabled, it completed the task or blocked it for the right reason. Turn off one layer and the same request predictably fails — sometimes by completing an action it should have refused.

Educational model. This lab runs a deterministic simulation in the browser; no real bookings, payments, or API keys are involved.
